## Go 里具体有什么，没什么

### 多出来的部分

- **不限次文本聊天**：可以在主力即时模型上持续对话。这个套餐上线时官方博客写的是 GPT‑5.2 Instant，目前帮助文档已更新为 GPT‑5.5 Instant，以最新文档为准。"不限次"有前提——受滥用防护限制，高峰期额度也可能临时收紧。
- **约为免费版 10 倍的消息、文件上传和图片生成额度**：这是 Go 最核心的卖点，官方原话就是让人"在 GPT‑5.2 Instant 上不用停下"。
- **更长的记忆和上下文**：ChatGPT 能记住更多关于你的细节，对话接得上之前的内容。
- **高级数据分析扩展使用**：可以更频繁地用 Python 这类工具做数据探索。
- **Projects、Tasks、自定义 GPT 和 Library**：整理工作、跟踪进度、创建和编辑自己的 GPT，Library 最多可存 4 GB 内容。
- **推理模型**：Go 也能用 Thinking，在输入框的"+"菜单里选择即可。
- **语音模式**：包含，但使用限额与免费版相同——这点官方写得很清楚，指望靠 Go 解锁无限语音的可以降低预期。

### 不包含的部分

- **Sora**：从 Plus 开始才提供。
- **4o 等旧模型**：Go 不含旧模型访问权限。
- **部分 Apps**：应用目录可以浏览，但个别应用需要 Plus 及以上订阅。
